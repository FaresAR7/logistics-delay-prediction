# Regional Logistics Delay Prediction

Machine learning project for predicting whether a logistics transfer
will be delayed by more than 30 minutes.

## Project Goal

The goal of this project is to build a binary classification model
that predicts significant logistics delays based on operational,
route and provider information.

## Models Used

- Logistic Regression
- Decision Tree
- Random Forest
- Linear SVM

## Main Steps

- Exploratory Data Analysis
- Data preprocessing
- Missing value handling
- Outlier handling
- Feature engineering
- One-Hot Encoding
- Scaling
- Model training
- Cross-validation
- ROC-AUC evaluation

## Results

The final Random Forest model achieved approximately:

- Validation ROC-AUC: 0.9993
- 5-Fold Cross Validation ROC-AUC: 0.9989

## Tools

Python, pandas, NumPy, matplotlib, scikit-learn, Jupyter Notebook
